# Solution

A browser game inspired by the game Sadie makes in Gabrielle Zevin's *Tomorrow, and Tomorrow, and Tomorrow*.

- `SPEC.md` is the source of truth for design, systems, content, endings, architecture and tuning values.
- `prototype.html` is the original one-file playable prototype. It is for reference only; don't extend it.
- Build in the milestone order in SPEC.md (M1 first: one good shift).
- Stack: TypeScript + Vite, a pure reducer, content as JSON, Vitest for tests.
- Follow the "Tone and content guidelines" section in SPEC.md for every line of text and every asset.
